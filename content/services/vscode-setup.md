### Trường hợp phù hợp
- Mới cài VS Code nhưng chưa biết cần cài thêm những extension nào cho môn học sắp tới.
- Soạn thảo code nhưng không có tính năng gợi ý cú pháp (IntelliSense) hoặc tự động format khi lưu.
- Muốn đồng bộ cài đặt (Settings Sync) và làm quen với các phím tắt giúp viết code nhanh hơn.

### Kết quả nghiệm thu cụ thể
- Cài đặt bản VS Code chính thức mới nhất.
- Cài đặt bộ extension chọn lọc theo ngành học của bạn (ví dụ: Python, C/C++, Markdown, GitLens).
- Kích hoạt tính năng tự động format code khi lưu file (`Format on Save`).
- Bảng tổng hợp các phím tắt hữu ích nhất trong VS Code để bạn thao tác nhanh hơn.

### Hỗ trợ sau buổi hẹn
- **Hỗ trợ 7 ngày:** Tụi mình hỗ trợ kiểm tra lại nếu có extension bị lỗi hoặc cài đặt bị thay đổi ngoài ý muốn.
